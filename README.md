# Solar-Energy-Company

A professional solar energy company website built with HTML, CSS, and JavaScript. Features a fully responsive design, animated stats counter, scroll reveal effects, testimonial slider, service detail pages, team section, FAQ accordion, and a validated contact form. Images sourced from Unsplash. Academic project by Kaleemllah.

## Pages
- **Home** — Hero, stats, services overview, how it works, projects gallery, testimonials
- **Services** — Residential solar, commercial solar, battery storage, add-ons
- **About** — Mission, company timeline, leadership team, certifications
- **Contact** — Quote form with validation, FAQ accordion, Google Maps

## Tech Stack
- HTML5, CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript (ES6+)
- Font Awesome icons
- Google Fonts (Inter)
- Unsplash images
